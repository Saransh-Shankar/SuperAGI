# SuperAGI Voice Generation Tool

The SuperAGI Voice Generation Tool helps you generate speech from text using CambAI's voice generation API.

## ⚙️ Installation

### 🛠 **Setting Up of SuperAGI**
Set up SuperAGI by following the instructions given [here](https://github.com/TransformerOptimus/SuperAGI/blob/main/README.MD)

### 🔧 **Configure CambAI API Key**

1. Navigate to the "Toolkit" page in SuperAGI's Dashboard and select "CambAI Voice Generation Toolkit"
2. Enter your CambAI API key in the configuration field
3. Save the configuration

## Running SuperAGI Voice Generation Tool

You can simply set one of the goals of your agent to generate speech from text, and the agent will use the Voice Generation Tool to create an audio file that will be placed in the Output folder of the Resource Manager, from where you'll be able to download it.
